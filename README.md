## Projeto Menu

### Projeto para conclusão do Capítulo 01 do Módulo 02 do Bootcamp DevJr - Abutua

Assuntos abordados no capítulo:
1. Realizar operações lógicas básicas em páginas HTML usando o JavaScript, como cálculos e alteração de valores dos elementos html e
estilos CSS.
2. Pesquisar e utilizar bibliotecas JavaScript de terceiros.
3. Fazer validações simples de entrada de usuários.
4. Inserir HTML de forma dinâmica.
5. Usar template strings e formatação monetária.
6. Trabalhar com array de objetos JavaScript.

O projeto consiste em elaborar uma página com um Menu, implementando os conhecimentos desenvolvidos no módulo.
